# UAT 与上线检查清单

## UAT 核心流程

- [ ] 管理员登录、刷新令牌、权限菜单和退出。
- [ ] 会员注册、登录、商品搜索、SKU 选择和库存提示。
- [ ] 加购、地址新增/编辑/默认设置、优惠券领取和核销。
- [ ] 创建订单、幂等重试、支付结果轮询、取消订单和确认收货。
- [ ] 后台发货、物流节点、售后申请/审核、退款和发票申请。
- [ ] 库存预占、取消释放、发货扣减、过期补偿和低库存预警。

## 上线前检查

- [ ] 执行数据库迁移清单校验：`shop-admin/db/migration/verify-migrations.ps1`。
- [ ] 注入生产环境变量，确认 JWT、数据库、Redis、MinIO、RocketMQ 和支付证书无默认值。
- [ ] 检查 Actuator 健康、指标端点及日志中的 `requestId`，确认敏感字段未输出。
- [ ] 运行后端编译、前端 lint/build 和安全扫描，记录构建产物版本号。
- [ ] 完成数据库、MinIO 和消息备份，并验证至少一次恢复可用。

## 生产冒烟

- [ ] `GET /api/health` 和 `/actuator/health` 返回成功。
- [ ] 管理端登录、门户登录各执行一次真实请求并检查审计日志。
- [ ] 创建一笔低金额测试订单，验证支付回调、库存流水、物流和通知链路。
- [ ] 灰度观察错误率、P95 延迟、消息堆积和数据库连接池，再逐步放量。
